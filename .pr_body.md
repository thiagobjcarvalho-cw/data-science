## 🔧 Como Executar Localmente

### Método 1: Script Automatizado (Recomendado)

```bash
git clone <repositório>
cd data-science
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
pip install -r requirements.txt
./executar_prova.sh
```

**Resultado:** 4 HTMLs prontos em `prova-aedi-unb/exports/` (~60-80 min)

### Método 2: Jupyter Interface

```bash
cd prova-aedi-unb/notebooks
jupyter notebook
# Execute manualmente cada notebook _plotly.ipynb
```

### Método 3: Linha de Comando Individual

```bash
cd prova-aedi-unb/notebooks
jupyter nbconvert --to html --execute Q1_Regressao_Linear_plotly.ipynb
jupyter nbconvert --to html --execute Q2_Regressao_Logistica_plotly.ipynb
jupyter nbconvert --to html --execute Q3_ANOVA_plotly.ipynb
jupyter nbconvert --to html --execute Q4_ML_Avancado_plotly.ipynb
```
